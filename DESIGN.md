# Progress panel visual direction

Operate mode. Inherit the conversation host's theme, type conventions and quiet utility presentation. A compact ordered stage rail carries status through words and restrained marks; color is supplementary. Current work precedes the list and a real blocker is explicit. No progress percentage or time estimate. Responsive at narrow widget widths; all task content renders as text. System fonts, no imagery, no remote assets, no animation needed for this read-only utility.
